# 📘 Gestor Acadêmico Web

Sistema Web desenvolvido para auxiliar estudantes no acompanhamento de seu desempenho acadêmico, permitindo registrar matérias, notas, faltas e calcular automaticamente médias e o IRA (Índice de Rendimento Acadêmico).

O projeto foi desenvolvido por **Gabriel Troni, Rafael de Paula e Renan Machado**.

O projeto é fruto da matéria de **Engenharia de Software II** no 3º Semestre do curso de Tecnologia em Análise e Desenvolvimento de Sistemas (ADS), no **IFSP – Campus Jacareí**.

---

## 📌 Objetivo do Sistema

O Gestor Acadêmico Web tem como finalidade fornecer ao estudante uma ferramenta clara, acessível de qualquer dispositivo e intuitiva para organizar suas disciplinas ao longo dos semestres, visualizar sua evolução e automatizar cálculos essenciais — como médias, faltas restantes e o Índice de Rendimento Acadêmico (IRA).

---

## 🧩 Funcionalidades Principais

### ✔️ Requisitos Funcionais

* **RF1 – Gerenciamento de Semestres:** criar e organizar múltiplos períodos letivos.
* **RF2 – Gerenciamento de Matérias:** adicionar, editar e remover disciplinas com informações completas.
* **RF3 – Registro de Avaliações:** inserir notas com pesos, recalculando automaticamente a média atual.
* **RF4 – Controle de Frequência:** registrar faltas e exibir o progresso visualmente.
* **RF5 – Persistência de Dados:** armazenamento seguro e automático em banco de dados relacional.
* **RF6 – Dashboard Principal:** visão geral das disciplinas com média atual e faltas.
* **RF7 – Cálculo de IRA:** ferramenta dedicada para cálculo do índice global de rendimento do aluno.

### 🔧 Requisitos Não Funcionais

* **RNF1 – Usabilidade:** interface amigável, responsiva e simples de navegar.
* **RNF2 – Desempenho:** respostas rápidas e otimização para acesso via web.
* **RNF3 – Portabilidade:** sistema web acessível através de qualquer navegador padrão em computadores, tablets ou smartphones.

---

## 🧭 Fluxo Geral de Uso

1. **Cadastro do Usuário** – Nome, curso, carga horária total e quantidade de semestres.
2. **Dashboard Principal** – Tela inicial com visualização geral das matérias.
3. **Gerenciamento de Semestres** – Criar, finalizar e organizar períodos.
4. **Registro de Matérias** – Cadastrar disciplinas com dados essenciais.
5. **Acompanhamento** – Inserção de notas, faltas e atualização automática da média.
6. **Cálculo do IRA** – Avaliação global do rendimento do estudante.

## 🧱 Modelagem do Sistema

O sistema foi estruturado com base em diversos modelos e diagramas para suportar a arquitetura Web e o banco de dados, incluindo:

* **Casos de Uso**
* **Mapa de Navegação**
* **Modelo Conceitual**
* **Diagrama de Classes**
* **Diagramas de Sequência**

Esses artefatos descrevem de forma detalhada o funcionamento interno da aplicação, suas rotas e interações com o banco de dados.
