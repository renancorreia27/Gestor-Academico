# Gestor Acadêmico Web

O **Gestor Acadêmico** é um sistema web intuitivo criado para simplificar e organizar a vida acadêmica de estudantes universitários. Em vez de depender de planilhas complexas, o aluno conta com um painel interativo para gerenciar todo o seu desempenho de forma centralizada.

## Principais Funcionalidades

* **Autenticação:** Criação de conta individual.
* **Organização por Semestres:** Agrupe suas disciplinas e acompanhe a evolução período a período.
* **Controle de Notas e Faltas:** Registre suas avaliações com diferentes pesos e monitore seu limite de faltas em tempo real.
* **Cálculos Automáticos:** O sistema recalcula instantaneamente sua média final e o Índice de Rendimento Acadêmico (IRA).

## Tecnologias Utilizadas

O projeto foi construído seguindo boas práticas de desenvolvimento web moderno:

* **Back-End:** Python 3 e microframework Flask.
* **Banco de Dados:** MySQL para persistência relacional.
* **Front-End:** HTML5, CSS3 Customizado e Bootstrap 5 para garantir responsividade (acessível no celular e no computador).
* **Segurança:** Hashes de senha utilizando a biblioteca `werkzeug.security`.
